## 1. Objective and contract

Implement and evaluate an optional **small, native-CPU, task-conditioned Choice model** with (a) one SHARED context/candidate nonlinear scorer and (b) separately trained permutation-invariant answerability (no-option) probability. Compare against SAME-feature existing legacy/cross/compositional Choice, deterministic rule oracle and a shallow boosted-tree benchmark. Declare learned-model quality DEV-ONLY, not qualifying or promoting it. Model size is a hypothesis, not proof of usefulness: two candidate hidden widths 32 and 64; provisional 5k–50k actual trainable parameters, bounded by the measured input dimension and artifact caps. Do not increase a cap or artificially pad weights to meet it.

Respect the existing `DecisionSpec::Choice` requirement of **2..=128 options**; 0/1 invalid requests must fail closed in the existing core, NOT turn into valid Choice(None) through an accidental API change. For 2+ valid options, `Choice(None)` means no eligible answer. The runtime returns only one supplied option ID or None, never constructs a new ID. CodeGG owns tool admission/permissions.

Non-goals: encoder pretraining, LLM, transformer, new tokenizer or network, CodeGG trajectories, Rust MSRV upgrade, default semantic change, new Rank/Binary/Score head, direct model publication, modifying any historical final file. Training/benchmark use newly generated M015 TRAIN/DEV ONLY.

## 2. Design and versioned artifact

A. Add the opt-in `sdm-typed-choice-tinymlp-v1` architecture with a distinct registered runtime dispatch and bounded validated payload (model parameters, tensor shape/dtype, encoder digest, schema, training SHA/fingerprint, dev calibration digest, output contract and task choice-only capability). Preserve `sdm-typed-task-v1`, cross and compositional artifacts byte-for-byte; v1 Rank wire remains unchanged. v2 artifact <=16 MiB, <=1M declared parameters, strict per-layer dimension multiplication and allocated-byte ceilings, candidate bound <=128 for Choice, finite weights and outputs, SHA checked before allocation/inference. Test malformed shape, oversized tensor, unsupported task, unknown category, corrupted weights, encoder/calibrator drift, and mismatched option IDs.

B. Share a bounded `FittedFeatureEncoderV2` fitted TRAIN-ONLY. For each permitted option i, concatenate context, candidate and (if needed) explicit bounded interactions then apply the SAME MLP with one or two compact hidden layers, e.g. `s_i = w_o^T activation(W[x_context,x_i]+b)+c`. No option-position input, position-dependent normalization, arbitrary ID hashing, or label/choice-derived feature leaks. Maintain semantic candidate characteristics where genuinely present as allowed typed input; do not assume yes/no ID strings encode correct targets. Confirm invariance of option reordering and stable ID renaming (after corresponding projection key relabeling), including raw scores and final choices modulo renaming.

C. Separate head `a = P(answerable | context, symmetric summary of options)` with e.g. bounded mean/max-pooling of learned option embeddings or logits; ensure order invariance. For answerable Choice use conditional softmax `p(i|answerable)`; for no-answer use Bernoulli `1-a`. Train jointly with `L = CE(answerability) + lambda * 1[answerable] * CE(correct permitted option)`, optionally ablate joint vs separate heads on DEV. Calibrate `a` and choice probabilities strictly on DEV; abstention/coverage threshold separate from rank accuracy and predeclared objective. Never include a `None` pseudo-option, and do not let threshold training leak a held-out label.

D. Define exact tensor flattening, initialization/seed, activation, loss, gradient, optimizer, numeric stability, update/batch bounds, epoch ceilings and early-stopping DEV policy. Test numerical gradient vs finite difference for both heads; test softmax under large logits, saturation and no-answer class imbalance. Two CPU training replicas with fixed seeds should produce exact/declared-tolerance outputs and identical artifact bytes if declared deterministic. Record any legitimately non-bitwise optimizer reproducibility; do not substitute tolerance for artifact identity.

E. Keep the native CPU inference-only crate isolated: no `sdm-training`, `sdm-eval`, Python/scikit-learn, GPU framework, network client or implicit downloads, and no startup work except validating named local artifacts. If considering Burn/Candle/tract, document a small dep/compile/MSRV/footprint spike first; prefer compact Rust math if it satisfies the required gradient and portability verification. No file IO in core math apart from existing caller's explicit loading boundary.

## 3. Baselines, controlled model selection and diagnostics

1. On M015 identical TRAIN/DEV split, fit/check existing linear/logistic, legacy/cross and compositional Choice wherever representation supports the task; report Unsupported where appropriate rather than silently omitting a baseline. Compare common candidate identities, encoders, rule descriptors and training data. Oracle provides correctness ceiling, not an ML contender.
2. Build a genuinely trained shallow-tree ensemble benchmark (e.g. a fixed small-depth gradient-boosted tree model) using locked offline-only build/tooling, with exact feature ordering, max depth/estimators/seed and exportable results. The baseline may remain research-only and NOT be loaded into the Rust runtime; choose a scoped Rust implementation or approved isolated Python development environment without network access at run time. Audit tree feature equivalence and schema—no target-derived or test-family ID features. If tree training cannot be reproduced under available resources, label tree comparison **indeterminate** and do not claim neural superiority to trees.
3. Run bounded train/dev grid: 32/64 widths, at most three independent seeds each, at most three DEV-selected learning rates and two regularization points (<=36 trained MLP configurations). Record all candidates, masks, gradients, learning curves, baseline scores and discarded failures; choose at most one MLP candidate/operating threshold solely on independent DEV metrics. Do not tune on M013a/M014/M014b FINAL, nor on future M017 final.
4. DEV diagnostics: answerable conditional accuracy, NLL, Brier (explicit multiclass conventions), answerability AUROC/AP, no-answer recall, false abstention, ECE/calibration bins, coverage/selective risk, option-id/order invariance, correct-on-both causal counterfactuals, stable nuisance-pair predictions, per-family/support CI. Include structural heldouts with and without rule information, preserving impossible rule-hidden control as its own result.
5. Ablations: context-only vs candidate-only, no answerability head vs explicit head, compositional feature removal, note/text-only nuisance perturbation, maximum relevant-candidate count and seed sensitivity; disclose any role-encoding shortcut. Reject a purported successful model if its raw logits are invariant to causal flips or depend on option ordering.

## 4. Failure, restart, resource and security

Use explicit local synthetic paths only. Train with bounded step/batch/epoch, checkpoint temp+atomic finalization, content-addressed fingerprints for seeds/data/preprocessing/config, resume only from exact source/optimizer identity; partial or interrupted runs never replace an accepted artifact. Detect nonfinite gradient/loss, incorrect label identity, train/dev leakage and schema drift. Preflight weight/activation multiplication to avoid OOM before allocation; measure peak RSS, model bytes, cold load, p50/p95 inference for 2/8/16/64/128 options (same model bytes) on Linux x86_64/Linux ARM64/macOS ARM64, naming unavailable hosts. The proposed sub-ms small-candidate target is aspirational: record measured host-specific actual latency, not inferred performance.

No application admission/disclosure/actuation authority; candidate pool supplied by caller and already allowed. Do not allow arbitrary code from an artifact, remote input, automatic data collection, external teacher API or telemetry. Record data redistribution/license provenance. Historical SHA-ledger files stay untouched. If previous semantic head behavior changes, STOP and isolate into a new additive format.
