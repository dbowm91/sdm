# SDM Planning Index

This directory follows the handoff convention in [003-planning-process.md](003-planning-process.md).

- [Registry](registry.md): authoritative milestone states and links to plans/evidence.
- [Roadmap](subsystems/general-decision-model-framework-roadmap.md): accepted architecture and long-term scope.
- [ADRs](adrs/): durable architecture decisions.
- [Implementation plans](implementation/general-decision-model-framework/): milestone scope and acceptance criteria.
- [Closure records](closure/general-decision-model-framework/): requirement-to-evidence outcomes.

Preserve frozen inputs, reports, and closure records. Historical plans remain available
for context; the registry is the source of current status.
